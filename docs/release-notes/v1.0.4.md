# CPAMP Mobile 1.0.4

## 中文

### 主要变化

- 修复概览 2x2 指标卡片文字裁切，并优化长文本与大数值布局。
- 概览和监控顶部现在正确遵守“隐藏地址”，地址型服务器名称也会被隐藏。
- 模型列表使用可追溯的供应商标志；未知模型继续使用通用图标。
- 删除监控搜索和整个资源管理栏目，将运行状态、日志、服务器管理统一为“运维”，设置成为独立一级栏目。
- 用量趋势支持点击、拖动和前后切换每个时间段，并显示请求、Token、成功、失败和成本详情。
- 支持生成今天、近 7 天、近 30 天的隐私安全用量图片；图片不包含服务器、密钥、凭据或账号信息。
- 设置中可手动检查 GitHub Release、下载更新，并在 SHA-256 与应用签名验证通过后交由 Android 安装器升级。

### 隐私与服务器负载

- Manager Server 数据仍仅在用户明确点击刷新或生成缺失范围的分享报告时读取。
- 没有后台轮询、启动刷新或定时读取。
- GitHub 更新检查使用独立客户端，不携带 Manager Admin Key。

### 安装要求

- Android 8.0（API 26）或更高版本。
- 使用应用内升级时，需要在系统中允许 CPAMP Mobile 安装未知应用；每次安装仍由 Android 安装器确认。

## English

### Highlights

- Fixed clipped text in the 2x2 overview metrics and improved long-label and large-value layout.
- Overview and Monitoring now fully honor Hide addresses, including profile names that are themselves URLs, IP addresses, or hosts.
- Model rows use traceable provider marks with a generic fallback for unknown models.
- Removed Monitoring search and the complete Resources management area. Operations now groups service status, logs, and saved servers, while Settings is a top-level destination.
- Every usage bucket can be selected by tap, drag, or previous/next controls to show requests, tokens, successes, failures, and cost.
- Added privacy-safe Today, 7-day, and 30-day usage images. Reports exclude server, key, credential, and account details.
- Added manual GitHub Release checks and in-app downloads. SHA-256 and signing-certificate continuity must pass before Android's installer opens.

### Privacy and server load

- Manager Server data is read only after an explicit refresh or when a requested share range is not already loaded.
- No background polling, launch refresh, or scheduled reads were added.
- GitHub update checks use an isolated client and never receive the Manager Admin Key.

### Requirements

- Android 8.0 (API 26) or newer.
- In-app upgrades require allowing CPAMP Mobile as an unknown-app installation source. Android still asks for explicit installation confirmation.
