# CPAMP Mobile 1.2.1

这一补丁版本改进了 Android Release 签名校验和故障诊断。

## 中文

- Release 流程现在会分别检查 Base64 编码、keystore 密码和签名别名，并给出不泄露密钥内容的明确错误信息。
- Base64 解码前会移除空白字符，兼容单行和换行格式的 keystore Secret。
- 发布文档补充了 Linux 与 PowerShell 的 keystore Base64 生成方式，以及本地密码和别名校验命令。
- 正式 APK 仍必须通过指定 keystore 签名；缺少或无效的签名配置会阻止发布。

## English

This patch improves Android Release signing validation and failure diagnostics.

- The Release workflow now validates Base64 data, the keystore password, and the signing alias separately with clear errors that do not expose key material.
- Whitespace is removed before Base64 decoding, supporting both single-line and wrapped keystore secrets.
- The release documentation now includes Linux and PowerShell Base64 commands plus local password and alias verification steps.
- Release APKs still require the configured keystore; missing or invalid signing configuration blocks publication.
