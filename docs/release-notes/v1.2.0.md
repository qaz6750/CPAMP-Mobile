# CPAMP Mobile 1.2.0

这一版本集中改善了概览信息密度、用量分享、导航体验和本地数据管理，并统一了认证后的数据刷新行为。

## 中文

### 概览与用量

- 概览加入按小时聚合的复合流量图，在同一区域展示请求与 Token 变化，时间趋势更容易比较。
- 进一步收紧 2x2 指标卡片的排版，大数值、长标签和辅助信息在小屏上更稳定。
- 用量分享按服务端实际返回的数据范围生成，不再把没有数据的日期算入报告。
- 分享图片重新设计，提供更清晰的指标、趋势、模型排行和时间范围，同时继续排除服务器、密钥、凭据与账号信息。

### 交互与外观

- 底部导航改为悬浮式布局，页面内容与系统手势区域之间的间距更自然。
- 浅色主题切换为天空蓝与白色视觉体系，提升信息层级和可读性。
- 登录或切换服务器成功后统一刷新概览、监控、用量和运维数据，减少页面间状态不一致。

### 设置与维护

- 设置中新增缓存清理，可移除本地缓存和临时分享文件，不影响已加密保存的服务器密钥。
- 延续手动刷新策略；除认证成功后的单次同步外，不新增后台轮询或定时请求。

### 安装与升级

- 支持 Android 8.0（API 26）及更高版本。
- 应用内升级会验证 Release APK 的 SHA-256 和签名证书，再交由 Android 系统安装器确认安装。

## English

This release improves overview density, usage sharing, navigation, local data maintenance, and post-authentication refresh consistency.

### Overview and usage

- Added an hourly composite traffic chart that compares request and token activity in one view.
- Refined the 2x2 metric cards for large values, long labels, supporting text, and smaller screens.
- Usage reports now use the actual data range returned by the server instead of including empty dates.
- Redesigned the share image with clearer metrics, trend details, model rankings, and date range while continuing to exclude server, key, credential, and account information.

### Interaction and appearance

- Replaced the bottom navigation with a floating layout that works more naturally with content and system gesture insets.
- Updated the light theme to a sky-blue and white visual system with clearer information hierarchy.
- Overview, Monitoring, Usage, and Operations now refresh consistently after authentication or a server switch.

### Settings and maintenance

- Added cache cleanup for local cached data and temporary share images without removing encrypted server keys.
- Preserved the manual-refresh policy; no background polling or scheduled Manager Server requests were introduced.

### Installation and updates

- Requires Android 8.0 (API 26) or newer.
- In-app updates verify the Release APK SHA-256 and signing certificate before opening Android's installer for confirmation.
