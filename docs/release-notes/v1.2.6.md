# CPAMP Mobile 1.2.6

这一版本重新打磨了应用的视觉层级，并让用量分析和分享报告更准确地还原 CPAMP 网页图表。

## 中文

### 📊 用量分析

- 用量趋势采用与 CPAMP 网页一致的请求、Token 和成本配色、平滑方式、动态坐标轴与时间桶范围。
- 请求健康趋势改为成功率与失败率折线配合平均延迟柱状图，并保留完整时间桶。
- Token 结构改为输入、输出、缓存和推理 Token 堆叠柱，并纳入缓存读取与缓存创建 Token。
- 三张用量图都提供自适应横轴和横屏完整视图，24 小时、7 天与 30 天范围更易查看。
- 修复概览中预估成本趋势缺失，以及横屏图表关闭后的方向恢复问题。

### 🖼️ 分享报告

- 分享图片提升至 1620 × 4350 分辨率，并改进文字、曲线、柱体与图标的抗锯齿效果。
- 修复 Token 结构标题受折线描边状态污染而显示异常的问题。
- 请求健康与 Token 结构图采用和应用内、CPAMP 网页一致的图形结构、数据口径与配色。

### ✨ 界面与更新

- 调整整体视觉层级、间距、背景与卡片表现，使主要信息更清晰、界面更轻量。
- 更新详情改为结构更稳定的弹窗，并确保下载期间始终可以关闭。
- 修复导航背景修饰符缺失导致的界面问题。

## English

This release refines the app's visual hierarchy and brings usage analytics and shared reports closer to the CPAMP web charts.

### 📊 Usage analytics

- Usage trends now match the CPAMP web colors, smoothing, dynamic axes, and bucket ranges for requests, tokens, and cost.
- Request health now combines success and failure rate lines with average-latency bars while preserving every time bucket.
- Token structure now uses stacked input, output, cached, and reasoning bars, including cache-read and cache-creation tokens.
- All three usage charts include adaptive horizontal axes and complete landscape views for 24-hour, 7-day, and 30-day ranges.
- Fixed the missing estimated-cost trend on Overview and orientation restoration after closing landscape charts.

### 🖼️ Shared reports

- Shared images now render at 1620 × 4350 with sharper text, lines, bars, and provider icons.
- Fixed malformed Token structure headings caused by leaked line-stroke paint state.
- Request health and Token structure sections now share the same chart structure, data definitions, and colors as the app and CPAMP web UI.

### ✨ Interface and updates

- Refined visual hierarchy, spacing, backgrounds, and card treatment for a lighter and clearer interface.
- Release details now use a more stable dialog layout that remains dismissible during downloads.
- Fixed a missing navigation background modifier.
