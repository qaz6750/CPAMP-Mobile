# CPAMP Mobile 1.4.1

此版本改进账号额度成本预估、多处界面细节与导航体验。

## 中文

### 📊 账号与额度

- 账号详情新增“预计可用到的成本”，按各账号最近一次额度重置推算周期总成本，避免按自然月高估。
- 账号筛选与健康概览改为两/三列自适应网格，取消左右滑动，并统一健康概览图标尺寸。

### 🎨 界面细节

- 移除账号详情中重复的提供商字段。
- 修复设置开关在关闭和禁用状态下的颜色显示。
- 已保存服务器改为独立卡片，分开展示当前状态与连接协议，并强化当前服务器的辨识。
- 重设计“关于与更新”卡片：分层展示版本、状态与操作，进行中显示进度而非灰色按钮。

### 🧭 导航与用量

- 底部导航新增共享滑动指示器，顶层页面按导航顺序左右滑动切换。
- 用量分析首次进入默认显示今天。

## English

This release improves account quota cost projection, several UI details, and navigation.

### 📊 Accounts and quota

- Account detail now projects the cost the account will reach by the end of its quota cycle, based on each account's most recent reset instead of the calendar month.
- Account filters and the health overview now use a responsive two/three-column grid without horizontal scrolling, with consistent health icon sizes.

### 🎨 UI details

- Removed the duplicate provider field from account detail.
- Fixed the visual appearance of setting switches in off and disabled states.
- Saved servers are now individual cards with separate active and connection status, and the active server is more prominent.
- Redesigned the About & updates card with layered version, status, and actions, showing progress instead of a disabled button while working.

### 🧭 Navigation and usage

- The bottom navigation now slides a shared selection indicator, and top-level pages slide in navigation order.
- Usage analytics defaults to today on first open.
