# CPAMP Mobile 1.2.11

这一版本集中改进了凭证额度、请求监控和系统运维，并统一了应用界面的视觉表现与指标格式。

## 中文

### 🔑 凭证额度

- 扩展多提供商凭证额度支持，并增强不同服务端版本和响应格式的兼容性。
- 未启用凭证也会显示，但不会发起无效额度请求。
- 优化失败、限流、不支持和过期额度状态，刷新失败时保留已有结果。
- 去除提供商、账号和套餐名称中的重复文本。
- 进入凭证额度页面后，底部导航会继续选中“监控”。

### 📊 概览与监控

- 概览用量趋势从本地当天 0 点开始，保留无请求时段并移除未来时间桶。
- “仅失败”现在直接筛选已加载的请求，减少重复网络请求。
- 今日请求卡增加成功与失败数量，Token 每分钟速率支持 K、M、B 动态单位。
- 请求详情改为统一的状态徽标和分组卡片布局。

### 🖥️ 系统与界面

- 系统运维页面新增 CPA 与 CPAMP 版本信息，并可感知服务端版本变化。
- 卡片统一使用不透明语义表面和边框，避免背景形状透入内容区域。
- 减细分享报告中的折线与节点，提高图表清晰度。
- 移除动态取色功能，使用应用定义的稳定亮色与暗色方案。

## English

This release focuses on credential quotas, request monitoring, and system operations while unifying the app's visual surfaces and metric formatting.

### 🔑 Credential quota

- Expanded provider-aware credential quotas with improved compatibility across server versions and response formats.
- Disabled credentials remain visible without triggering unnecessary quota requests.
- Improved failed, rate-limited, unsupported, and stale quota states while preserving existing results after refresh failures.
- Removed duplicated provider, account, and plan labels.
- The Monitoring destination remains selected when opening the credential quota screen.

### 📊 Overview and monitoring

- Overview usage trends now begin at local midnight, preserve hours without requests, and exclude future buckets.
- Failed-only filtering now works on loaded requests without repeating network calls.
- Request metrics include success and failure counts, while Token rates use dynamic K, M, and B units.
- Request details now use consistent status badges and grouped semantic cards.

### 🖥️ System and interface

- System Operations now shows CPA and CPAMP versions and observes server version changes.
- Cards use opaque semantic surfaces and borders to prevent background shapes from showing through.
- Reduced line and marker weight in shared report charts for clearer rendering.
- Removed dynamic colors in favor of stable app-defined light and dark palettes.
