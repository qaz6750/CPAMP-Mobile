# CPAMP Mobile 1.4.5

本版本为移动端界面提供更紧凑的图表与排行布局，为底部导航加入液态玻璃效果，并提高发布构建的稳定性。

## 中文

### 📊 移动端布局

- 将图表选中点的日期保持为单行显示，并把详情指标压缩为双列布局，减少纵向空间占用。
- 缩小用量排行条目之间的间距，让排行卡片在移动端展示更多内容。
- 降低浮动底部导航栏高度，同时保留图表控件的可访问点击区域。

### ✨ 底部导航

- 使用 Backdrop 对页面内容进行实时采样，为移动端底部导航加入模糊、色彩增强、镜头折射、高光与阴影效果。
- 为不支持完整图形效果的旧版 Android 提供高不透明度回退，保持导航内容清晰可读。

### 🛠️ 发布构建

- 将 Debug 单元测试与 Release lint、打包拆分为独立 Gradle 调用，并限制并行工作进程。
- 在发布流水线中关闭 KSP 增量状态，避免跨构建变体的工作缓存损坏。

## English

This release makes mobile charts and rankings more compact, adds a liquid glass bottom navigation effect, and improves release build stability.

### 📊 Mobile layouts

- Kept selected chart dates on one line and arranged detail metrics in two columns to reduce vertical space usage.
- Reduced spacing between usage ranking entries so mobile ranking cards show more content.
- Lowered the floating bottom navigation height while preserving accessible chart control targets.

### ✨ Bottom navigation

- Added live content sampling with Backdrop to give the mobile bottom navigation blur, vibrancy, lens refraction, highlights, and shadows.
- Added a higher-opacity fallback for older Android versions that do not support the complete graphics effects.

### 🛠️ Release builds

- Split Debug unit tests from Release lint and assembly into separate Gradle invocations and limited parallel workers.
- Disabled KSP incremental state in the release pipeline to prevent cross-variant worker cache corruption.
