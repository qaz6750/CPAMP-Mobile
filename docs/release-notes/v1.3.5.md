# CPAMP Mobile 1.3.5

这一版本进一步优化请求筛选与详情界面，并提高用量报告分享图片的清晰度。

## 中文

### 🔎 请求筛选

- 模型和提供商改为从已有请求数据中直接选择，不再需要手动输入。
- 支持同时选择多个模型和提供商，并保留已发现的可选项。
- 移除最低延迟筛选，使常用筛选流程更直接。
- 缩小筛选卡片的内边距、间距和控件高度，减少监控页空间占用。
- 修复带筛选条件的缓存策略，以及刷新期间切换条件可能导致加载状态无法结束的问题。

### 🧾 请求详情

- 放大请求详情卡片，为较长的模型、提供商、账号和错误信息提供更多空间。
- 详情弹窗改用应用统一的卡片圆角、表面颜色、分隔线和底部操作布局。
- 详情内容保持独立滚动，在较小屏幕上仍可完整查看。

### 🖼️ 分享图片

- 用量报告分享图从 `1620 × 4350` 提升到 `2160 × 5800`，文字和图表更加清晰。
- 图片写入完成后主动释放高分辨率位图，减少持续内存占用。

## English

This release further improves request filtering and request details while increasing the clarity of shared usage report images.

### 🔎 Request filters

- Models and providers are now selected directly from discovered request data instead of entered manually.
- Multiple models and providers can be selected while previously discovered options remain available.
- Removed the minimum latency filter to keep the common filtering flow more direct.
- Reduced filter card padding, spacing, and control height to use less space on the monitoring page.
- Fixed filtered-response caching and a loading state that could remain active when conditions changed during refresh.

### 🧾 Request details

- Enlarged the request details card to provide more room for model, provider, account, and error information.
- The details dialog now uses the app's standard card radius, surface color, divider, and bottom action layout.
- Details remain independently scrollable for complete access on smaller screens.

### 🖼️ Shared images

- Increased usage report image resolution from `1620 × 4350` to `2160 × 5800` for clearer text and charts.
- High-resolution bitmaps are now released immediately after writing to reduce retained memory usage.
