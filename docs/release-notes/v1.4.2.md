# CPAMP Mobile 1.4.2

本版本统一账号与设置界面的视觉结构，提升响应式布局和无障碍体验，并优化标签发布流程。

## 中文

### 📊 账号与额度

- 重新设计账号详情页，将身份摘要、额度、本轮用量和数据来源组织为统一的信息层级。
- 将额度概览移至账号详情首屏核心位置，突出剩余百分比、进度和重置时间。
- 用量指标改为带图标的响应式连续网格，并合并预计周期成本信息。
- 账号列表改为紧凑的提供商筛选、三段健康概览和连续账号列表。
- 改善详情加载、文字截断、缓存提示和窄屏大字体显示。

### ⚙️ 设置

- 统一服务器、安全、外观、缓存和更新区域的标题、边框、分隔线与间距。
- 服务器管理改为连续列表，集中展示连接协议、当前服务器和操作。
- 规范设置开关的触控高度，并整理锁定延迟、语言和主题选项。
- 更新状态、主操作、更新详情和许可证入口采用统一分组结构。

### 📱 响应式与发布

- 改善多个界面的响应式布局、动态字体适配、触控目标和内容可访问性。
- 标签发布时不再重复构建 Debug APK，并让 CI 运行标题仅使用提交标题。

## English

This release unifies the account and settings interfaces, improves responsive and accessible layouts, and streamlines tag releases.

### 📊 Accounts and quota

- Redesigned account details around a consistent hierarchy for identity, quota, current usage, and data source information.
- Moved quota to the primary first-screen position with prominent remaining percentages, progress, and reset times.
- Reworked usage metrics into an icon-led responsive grid and integrated projected cycle cost.
- Simplified the account list with compact provider filters, a three-state health overview, and continuous account rows.
- Improved detail loading, text truncation, cache notices, narrow screens, and large font behavior.

### ⚙️ Settings

- Unified titles, borders, dividers, and spacing across server, security, appearance, cache, and update sections.
- Converted server management into a continuous list with connection protocol, active server state, and actions together.
- Standardized switch touch targets and reorganized lock delay, language, and theme options.
- Aligned update status, primary actions, update details, and license links within one grouped structure.

### 📱 Responsive UI and releases

- Improved responsive layouts, dynamic font handling, touch targets, and content accessibility across the app.
- Tag releases no longer rebuild the Debug APK, and CI run titles now capture only the commit title.
