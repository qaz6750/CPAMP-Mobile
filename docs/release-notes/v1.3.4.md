# CPAMP Mobile 1.3.4

这一版本为请求监控加入更完整的筛选能力，并改进筛选界面、请求详情和凭证额度兼容性。

## 中文

### 🔎 请求筛选

- 新增模型和提供商筛选，支持使用逗号同时指定多个值。
- 新增最低延迟筛选，可快速查看 500、1000 或 2000 毫秒以上的请求。
- 时间范围、失败状态和高级条件会统一发送到 Manager Server，使统计摘要与请求列表保持一致。
- 高级筛选支持折叠，并显示已启用条件数量，减少监控页首屏占用。
- 输入框改为适合手机宽度的纵向布局，延迟选项在窄屏和大字体下可自动换行。

### 🧾 请求详情与凭证额度

- 请求详情补充服务来源、提供商、账号和思考 Token，并优化弹窗尺寸与耗时状态显示。
- 增强凭证额度响应解析，兼容不同形式的字段和成功状态。

## English

This release adds more complete request monitoring filters and improves the filter layout, request details, and credential quota compatibility.

### 🔎 Request filters

- Added model and provider filters with comma-separated multi-value input.
- Added minimum latency filters for quickly finding requests above 500, 1000, or 2000 milliseconds.
- Time range, failure status, and advanced conditions are now sent together to Manager Server so summaries and request events remain consistent.
- Advanced filters can be collapsed and show the number of active conditions, reducing first-screen usage on the monitoring page.
- Inputs now use a phone-friendly vertical layout, while latency options wrap on narrow screens and with larger fonts.

### 🧾 Request details and credential quotas

- Request details now include service source, provider, account, and reasoning tokens, with improved dialog sizing and duration states.
- Credential quota parsing now accepts additional field and success-response variants.
