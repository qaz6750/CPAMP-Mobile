# CPAMP Mobile 1.2.7

这一版本改进了用量统计与额度显示，优化了分享图表现，并修复了更新说明与调试版本安装问题。

## 中文

### 📊 用量与额度

- 优化用量分析的时间范围划分，统计结果更贴近所选区间。
- 改进凭据额度的解析与展示，额度信息更完整准确。
- 调整仪表盘与分析图表的绘制细节，显示更稳定。

### 🖼️ 分享报告

- 重新调整用量分享图的排版与配色，导出效果更清晰。

### 🔄 更新与安装

- 更新说明按系统语言显示，不再混杂其他语言与资源清单内容。
- 调试版本不再使用独立包名，可直接覆盖安装已发布的正式版本。
- 调试版本在 CI 中使用正式签名构建。

## English

This release improves usage analytics and quota reporting, refines shared report styling, and fixes release notes and debug installation issues.

### 📊 Usage and quota

- Refined time-range bucketing so usage analytics better match the selected range.
- Improved credential quota parsing and presentation for more complete and accurate values.
- Adjusted dashboard and analytics chart rendering for more stable output.

### 🖼️ Shared reports

- Reworked the usage share image layout and colors for a cleaner export.

### 🔄 Updates and installation

- Release notes now follow the system language instead of mixing languages and asset tables.
- Debug builds no longer use a separate application ID and can upgrade an installed release build.
- Debug builds are now signed with the release key in CI.
