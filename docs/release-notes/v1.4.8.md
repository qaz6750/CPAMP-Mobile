# CPAMP Mobile 1.4.8

本版本进一步完善浮动玻璃导航和账号额度体验，让停用账号、GPT 重置周期与 OpenAI 账号信息呈现更加清晰，同时精简重复状态文案。

## 中文

### ✨ 导航与视觉

- 重塑手机底部浮动导航，增强磨砂玻璃、背景折射、高光和阴影层次。
- 将选中项改为独立浮起的玻璃块，并保留自然的弹性切换反馈。
- 提亮浅色主题错误红色，使失败和临界额度状态更加醒目。

### 📊 账号与额度

- 支持为未启用但具备直接查询能力的账号加载并显示额度信息。
- 为 OpenAI 主额度窗口增加 GPT 标识，清晰展示各额度周期及其重置时间。
- 移除 OpenAI 图标旁重复的 Codex 文字，并将 provider 兜底名称统一为 OpenAI。
- 移除“额度可用”“未启用”“查询失败”等状态胶囊，保留额度百分比、进度、风险颜色和重置时间等有效信息。

### 🛠️ 稳定性

- 同步更新 OpenAI 账号标题测试期望，保持自动化测试与新版界面文案一致。

## English

This release further refines the floating glass navigation and account quota experience, improves disabled-account and GPT reset visibility, and removes repetitive OpenAI status labels.

### ✨ Navigation and visuals

- Redesigned the mobile floating navigation with stronger frosted glass, backdrop refraction, highlights, and shadow depth.
- Promoted the selected destination into an independently elevated glass surface while preserving responsive spring feedback.
- Brightened the light-theme semantic error red for clearer failure and critical-quota states.

### 📊 Accounts and quotas

- Added quota loading for disabled accounts that still support direct provider queries.
- Added GPT labels to OpenAI primary quota windows so each period and reset time is clearly identified.
- Removed redundant Codex text beside OpenAI icons and standardized the provider fallback name as OpenAI.
- Removed status pills such as quota available, disabled, and failed while retaining percentages, progress, risk colors, and reset times.

### 🛠️ Reliability

- Updated the OpenAI account-title test expectation to match the refined interface wording.
