# CPAMP Mobile 1.2.8

这一版本重新整理了凭证额度与请求监控体验，改进了用量排行、指标单位和分享报告的可读性，并增强了设置与会话操作的稳定性。

## 中文

### 🔑 凭证额度

- 凭证额度改为独立页面，并按已启用与未启用状态分组展示。
- 未启用凭证现在也会显示，同时避免对其发起无效的额度请求。
- 额度进度条会根据使用比例切换提示色，更容易识别接近上限的凭证。

### 📊 请求与用量

- 精简请求卡片和概览指标，减少重复的接口与每分钟请求信息。
- 优化 Token 紧凑单位与延迟单位，数值更准确、更易读。
- 修复切换用量排行条件后列表未及时刷新的问题。

### 🖼️ 分享与稳定性

- 提高分享报告头部、指标色条和辅助文字的对比度。
- 改善外观设置、应用锁、服务器配置和会话操作失败时的处理。

## English

This release reorganizes credential quotas and request monitoring, improves usage rankings, metric units, and shared-report readability, and strengthens settings and session reliability.

### 🔑 Credential quota

- Credential quota now opens as a dedicated screen, grouped into active and disabled credentials.
- Disabled credentials are now visible without triggering unnecessary quota requests.
- Quota progress bars use threshold-aware colors to make credentials near their limits easier to identify.

### 📊 Requests and usage

- Simplified request cards and overview metrics by removing duplicated endpoint and requests-per-minute details.
- Improved compact Token formatting and dynamic latency units for clearer, more accurate values.
- Fixed usage rankings not refreshing immediately after changing the selected ranking criteria.

### 🖼️ Sharing and reliability

- Increased contrast in the shared report header, metric accents, and supporting text.
- Improved failure handling for appearance settings, app lock, server profiles, and session operations.
