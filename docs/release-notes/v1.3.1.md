# CPAMP Mobile 1.3.1

这一版本移除界面卡片的描边，并改进 Manager Server 巡检启动冲突与服务端错误的提示。

## 中文

### 🎨 卡片外观

- 彻底移除登录、概览指标、图表、监控、请求事件、预览和设置页面的卡片描边。
- 保留输入框、按钮和筛选标签等交互控件原本需要的轮廓。
- 卡片继续通过背景色和内容层级区分，不再出现深色线框包裹。

### 🔍 巡检启动诊断

- Manager Server 返回 HTTP 409 时，明确提示已有巡检正在运行，避免误报为启动失败。
- HTTP 405 现在识别为当前 Manager Server 不支持启动巡检。
- 其他服务端启动错误会显示 HTTP 状态码，便于区分请求错误、接口限制和服务端故障。
- 无权限、网络错误和限流状态继续使用对应的独立提示。

## English

This release removes card outlines across the interface and improves Manager Server inspection conflict and error reporting.

### 🎨 Card appearance

- Removed card outlines from login, overview metrics, charts, monitoring, request events, previews, and settings.
- Preserved the expected outlines on interactive controls such as text fields, buttons, and filter chips.
- Cards now rely on surface colors and content hierarchy without dark framing lines.

### 🔍 Inspection diagnostics

- HTTP 409 now indicates that an inspection is already running instead of reporting a generic start failure.
- HTTP 405 is recognized as an unsupported inspection-start operation on the current Manager Server.
- Other server-side start failures display the HTTP status code to distinguish request, endpoint, and server errors.
- Unauthorized, network, and rate-limit failures keep their dedicated messages.
