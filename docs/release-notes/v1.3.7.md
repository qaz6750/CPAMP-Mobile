# CPAMP Mobile 1.3.7

这一版本重点提升 Accounts 健康中心的数据可靠性和额度可读性，并进一步统一 CPA-Manager-Plus 的界面状态与配色。

## 中文

### Accounts 数据与额度

- 修复有效额度被显示为 `0%` 的问题，并稳定额度进度、阈值和状态标签。
- 禁用账号现在仍会展示服务器返回的额度窗口，同时清楚标记账号不可用状态。
- 统一 direct quota 与 inspection 数据的合并规则；direct 请求失败时保留检查结果和失败提示，避免丢失可用额度。
- 归一化 OpenAI/Codex 等提供商别名，确保筛选、统计和账号详情使用一致身份。
- 健康概览改为互斥分类，避免同一账号被重复计入多个状态。
- 更新隐私安全缓存格式，避免持久化账号身份信息。

### UI 与配色

- 将主交互统一为 CPA-Manager-Plus 蓝色体系，并将界面中性色与图表数据色分离。
- 图表采用一致的 Blue、Teal、Green、Red 和 Amber 数据色板，同时适配浅色与深色主题。
- 统一 Accounts、Overview、Usage、Login 和 Settings 的玻璃表面、边框和提示状态。
- 底部导航和宽屏导航使用浅蓝激活面，提升当前页面的识别度。
- Settings 使用统一页面标题结构，信息提示与错误提示分别使用蓝色和红色语义容器。

## English

This release improves the reliability and readability of the Accounts health center and further aligns interface states and colors with CPA-Manager-Plus.

### Account data and quotas

- Fixed valid quota values being displayed as `0%`, with stable progress, thresholds, and status labels.
- Disabled accounts now retain server-provided quota windows while clearly showing that the account is unavailable.
- Unified direct quota and inspection merge behavior; inspection data and failure context remain available when a direct request fails.
- Normalized provider aliases such as OpenAI and Codex so filters, metrics, and account details use consistent identities.
- Made health overview categories mutually exclusive to prevent accounts from being counted in multiple states.
- Updated the privacy-safe cache format to avoid persisting account identity data.

### UI and colors

- Standardized primary interactions on the CPA-Manager-Plus blue palette and separated neutral interface colors from chart data colors.
- Updated charts to a consistent Blue, Teal, Green, Red, and Amber data palette for both light and dark themes.
- Unified glass surfaces, borders, and notice states across Accounts, Overview, Usage, Login, and Settings.
- Added light-blue active surfaces to bottom and wide-screen navigation for clearer destination feedback.
- Reused the shared page header in Settings and separated informational blue notices from red error notices.
