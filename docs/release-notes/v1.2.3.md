# CPAMP Mobile 1.2.3

这一补丁版本集中改进凭据、会话、更新与监控缓存的安全边界，同时减少无效网络、状态和界面工作。

## 中文

- 加固本地凭据生命周期：密文与服务器资料绑定，凭据写入串行化，并在取消、保存失败、切换或删除服务器时可靠回滚与清理。
- 规范化服务器地址并关闭被替换的网络客户端，避免等价地址产生歧义、旧会话残留或闲置连接继续占用资源。
- 修复协程取消传播和会话切换时序，防止已取消任务继续提交过期状态或阻塞新服务器请求。
- 加固应用内更新：仅信任约定的 HTTPS 发布资源，将校验清单绑定到目标 APK，并把下载与清理限制在应用更新目录。
- 监控缓存进一步移除请求标识、账户标签、路径和失败摘要，降低离线缓存暴露敏感运维信息的风险。
- 用生命周期感知方式收集应用状态、原子更新界面状态，并按导航目标惰性创建 ViewModel，减少后台收集、重复重组和不必要初始化。
- 优化会话客户端复用：删除非活动服务器时保留当前连接，并在替换会话时及时释放旧客户端。
- 改进用量趋势、模型排行和分享图表；切换时间范围时会正确刷新，临时界面状态也能在导航后保留。
- 补充加载操作的无障碍标签，并修正 Claude 品牌图标颜色。

## English

This patch strengthens credential, session, update, and monitoring-cache boundaries while reducing unnecessary network, state, and UI work.

- Hardened the local credential lifecycle by binding ciphertext to server profiles, serializing credential writes, and reliably rolling back or cleaning up after cancellation, persistence failures, server switches, and profile deletion.
- Normalized server URLs structurally and closed replaced network clients to avoid ambiguous equivalent addresses, stale sessions, and idle connection resources.
- Fixed coroutine cancellation propagation and session-switch ordering so cancelled work cannot commit stale state or delay requests for the new server.
- Hardened in-app updates by trusting only expected HTTPS release assets, binding checksum manifests to their target APK, and confining downloads and cleanup to the app update directory.
- Removed request identifiers, account labels, paths, and failure summaries from the monitoring cache to reduce exposure of sensitive operational data at rest.
- Added lifecycle-aware app-state collection, atomic UI-state updates, and lazy destination ViewModel creation to reduce background collection, redundant recomposition, and unnecessary initialization.
- Improved session-client reuse by preserving the active connection when an inactive profile is deleted and promptly closing replaced clients.
- Refined usage trends, model rankings, and shared charts; changing the time range now refreshes correctly, and transient screen state survives navigation.
- Added accessibility labels to loading actions and corrected the Claude brand icon color.
