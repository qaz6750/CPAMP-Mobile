# CPAMP Mobile 1.4.9

本版本重点优化浮动玻璃导航的兼容性与响应速度，重构账号额度界面，并接入真实的 Codex 限额重置权益查询与使用流程。

## 中文

### ✨ 导航与视觉

- 优化浮动玻璃导航的交互、尺寸和选中态表现，减少首次切换时的延迟。
- 修复 Backdrop 兼容性问题，使导航玻璃效果在不同环境下更加稳定。
- 移除卡片的多余描边，统一界面层次和视觉密度。

### 📊 账号与额度

- 重构账号列表和详情页，以紧凑进度条展示主要额度周期，并改善停用账号状态的呈现。
- 恢复并优化 OpenAI 额度周期、重置时间和风险状态展示。
- 在详情页加入账号状态、额度周期、本轮用量、预计成本和数据来源等分区信息。
- 接入真实 Codex 限额重置权益数量和过期时间，不再将 5 小时或 7 天额度周期误作重置次数。
- 支持核验并使用 Codex 重置权益，同时处理无可用次数、查询失败、使用成功及刷新失败等状态。

### 📤 分享报告

- 精简用量分享图片，移除“请求健康趋势”区块并缩短输出长图高度。

## English

This release improves floating glass navigation compatibility and responsiveness, redesigns the account quota experience, and adds real Codex rate-limit reset credit support.

### ✨ Navigation and visuals

- Refined floating glass navigation interactions, dimensions, and selected states while reducing first-switch latency.
- Fixed Backdrop compatibility for more reliable glass rendering across environments.
- Removed redundant card outlines for a cleaner and more consistent visual hierarchy.

### 📊 Accounts and quotas

- Redesigned account lists and details around compact quota progress rows with clearer disabled-account states.
- Restored and refined OpenAI quota periods, reset times, and risk presentation.
- Added sectioned account details for status, quota windows, current-cycle usage, projected cost, and data source information.
- Added real Codex reset credit counts and expiry details without confusing five-hour or seven-day quota windows with reset credits.
- Added verification and redemption flows for Codex reset credits, including unavailable, failed, successful, and partial-refresh states.

### 📤 Shared reports

- Simplified shared usage images by removing the request health trend section and reducing the output image height.
