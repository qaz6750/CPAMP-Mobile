# CPAMP Mobile 1.3.2

这一版本新增 Manager Server 实时凭证额度查询、指定月份用量报告分享，并将应用更新迁移到独立页面。

## 中文

### 📊 实时凭证额度

- 凭证额度页现在通过 Manager Server 实时查询当前启用账号，不再依赖最近一次巡检结果。
- 支持 Antigravity、Claude、Codex、Kimi 和 xAI，并按不同提供商展示对应的额度周期。
- 单个账号查询失败不会影响其他账号，禁用账号不会发起请求。
- 提供商访问令牌仍由 Manager Server 代为注入，手机端不会获取或保存真实令牌。

### 📅 指定月份报告

- 用量分析新增指定月份选项，可以选择最近月份并分享对应自然月的报告。
- 历史月份覆盖完整自然月，当前月份仅统计到当前时间。
- 月份边界按设备时区计算，避免跨时区导致日期偏移。

### ⬆️ 独立更新页面

- 版本信息、更新说明、下载、校验和安装操作已集中到独立更新页面。
- 设置页保留版本与更新状态摘要，并提供稳定的更新页面入口。
- 更新页面继续展示下载进度和安装状态，并说明安装包校验与安全策略。

## English

This release adds live credential quota queries through the Manager Server, usage report sharing for a selected month, and a dedicated app update screen.

### 📊 Live credential quotas

- The credential quota screen now queries enabled accounts live through the Manager Server instead of relying on the latest inspection results.
- Antigravity, Claude, Codex, Kimi, and xAI are supported with provider-specific quota windows.
- A failed account query no longer blocks other accounts, and disabled accounts are skipped.
- Provider access tokens are still injected by the Manager Server; the mobile app never receives or stores the real tokens.

### 📅 Reports for a selected month

- Usage analytics now lets you select a recent month and share a report for that calendar month.
- Past months cover the complete calendar month, while the current month ends at the current time.
- Month boundaries follow the device time zone to avoid date shifts across time zones.

### ⬆️ Dedicated update screen

- Version details, release notes, download, verification, and installation actions now live on a dedicated update screen.
- Settings keeps a version and update status summary with a stable entry point to the update screen.
- The update screen continues to show download and installation status while documenting package verification safeguards.
