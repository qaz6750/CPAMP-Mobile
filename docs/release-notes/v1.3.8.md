# CPAMP Mobile 1.3.8

这是一个针对 `1.3.7` 发布构建的热修复版本。

## 中文

- 补齐 Settings 导航所需的中英文 `nav_settings` 字符串资源。
- 修复 `SettingsScreen` 在 `kspDebugKotlin` 阶段因找不到 `R.string.nav_settings` 而导致的构建失败。
- 统一 Settings 页面标题与应用导航使用的资源定义。

## English

This is a hotfix for the `1.3.7` release build.

- Added the missing English and Simplified Chinese `nav_settings` string resources.
- Fixed the `kspDebugKotlin` build failure caused by the unresolved `R.string.nav_settings` reference in `SettingsScreen`.
- Unified the string resource used by the Settings page header and app navigation.
