# CPAMP Mobile 1.4.7

本版本优化移动端导航与页面性能，重构仪表盘和账号界面的信息层级，并将玻璃质感、圆角与语义色统一到新的视觉体系。

## 中文

### ⚡ 导航与性能

- 移除底部顶层页面的重叠转场，减少页面切换期间的重复绘制和合成开销。
- 降低浮动导航的模糊与渲染成本，同时恢复清晰的胶囊选中指示器和自然的交互反馈。
- 保留旧版 Android 的高不透明度回退，确保不支持完整图形效果的设备仍然清晰可用。

### 📊 仪表盘与账号

- 重新组织手机仪表盘，使页头、四项概览指标和更大的用量趋势图能在紧凑屏幕上高效呈现。
- 简化账号列表与详情层级，压缩账号健康概览，并统一 provider 图标的圆形外观。
- 新增完整的开源许可页面，集中展示应用及依赖组件的许可信息。

### ✨ 视觉统一

- 将共享卡片、用量趋势和账号身份摘要统一为轻量半透明玻璃表面，并限制实时模糊范围以兼顾性能。
- 统一应用圆角 token，修正浅色与深色主题的错误语义色及其容器对比度。
- 调整卡片高光、边框和表面透明度，使内容层级更清晰且保持一致。

## English

This release improves mobile navigation and page performance, restructures dashboard and account information hierarchy, and unifies glass surfaces, corner radii, and semantic colors under a refined visual system.

### ⚡ Navigation and performance

- Removed overlapping transitions between bottom-level destinations to reduce duplicate drawing and composition work during navigation.
- Reduced floating navigation blur and rendering cost while restoring a clear capsule indicator and natural interaction feedback.
- Preserved the high-opacity fallback on older Android versions for reliable readability without full graphics effects.

### 📊 Dashboard and accounts

- Reorganized the phone dashboard so the header, four overview metrics, and a larger usage trend chart fit compact screens efficiently.
- Simplified account list and detail hierarchy, condensed the account health overview, and standardized circular provider icons.
- Added a comprehensive open-source licenses screen for the application and bundled dependencies.

### ✨ Visual consistency

- Unified shared cards, the usage trend, and account identity summary with lightweight translucent glass surfaces while limiting live blur for performance.
- Standardized application corner tokens and corrected error semantic colors and container contrast in light and dark themes.
- Refined card highlights, borders, and surface opacity for clearer and more consistent content hierarchy.
