# CPAMP Mobile 1.2.5

这一版本集中优化用量趋势、分享报告、请求监控和应用内更新体验。

## 中文

### 📊 趋势图

- 概览启动后保持同一套趋势数据，不再因数据源切换连续跳变。
- 用量趋势新增横屏完整视图，并正确处理屏幕旋转和关闭后的方向恢复。
- 增大趋势绘图区，压缩两侧坐标占用，让请求、Token 和成本曲线更易查看。

### 🖼️ 分享报告

- 分享图使用完整的 CPAMP Mobile 品牌，不再显示含义不明的“CP”。
- 趋势图增加面积层、细化网格、更多时间刻度和采样点，更清楚地呈现峰谷变化。
- 标题和空状态改用报告的真实日期范围，不再固定显示“今日”。

### ⏱️ 监控与更新

- “仅失败”筛选使用红色错误语义，失败过滤状态更加醒目。
- 请求事件和 P95 延迟会根据数值自动显示毫秒或秒。
- 修复应用内更新的 GitHub 仓库路径，能够正确识别签名 APK 和 SHA-256 文件。
- 更新页仅显示发行说明正文，不再展开下载、完整性和构建日志段。
- 修复横屏趋势使用 Activity Context 转换导致的 Android Lint 阻断。

## English

This release focuses on usage trends, shared reports, request monitoring, and the in-app update experience.

### 📊 Trends

- The Overview trend now keeps one consistent data source during startup, avoiding consecutive visual jumps.
- Usage trends now include a full landscape view with reliable orientation restoration after rotation or dismissal.
- The plot area is larger and side axes are more compact, giving request, token, and cost lines more room.

### 🖼️ Shared reports

- Shared images use the full CPAMP Mobile brand instead of the unclear “CP” label.
- Trend rendering now includes an area layer, finer grid levels, more time ticks, and sampled points for clearer peaks and valleys.
- Titles and empty states use the report's actual date range instead of a fixed “Today” label.

### ⏱️ Monitoring and updates

- The failed-only filter now uses the red error color for clearer status recognition.
- Request-event and P95 latency values automatically switch between milliseconds and seconds.
- Fixed the GitHub repository path used by in-app updates so signed APK and SHA-256 assets are recognized correctly.
- The update screen now shows release notes only, without generated download, integrity, and build-log sections.
- Fixed the Activity Context access that caused Android Lint to block the landscape trend build.
