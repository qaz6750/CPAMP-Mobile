# CPAMP Mobile 1.2.2

这一补丁版本新增只读凭证额度，并改进签名流水线与指标卡布局。

## 中文

- 运维页新增凭证额度入口，可查看当前启用的 Codex 凭证、套餐，以及 5 小时和每周额度的已用比例、剩余比例与重置时间。
- 凭证额度通过 Manager Server 安全查询，真实 OAuth Token 不进入 Android 客户端，额度响应也不会写入本地缓存。
- Debug 与 Release 现在使用两套独立的 GitHub Secrets 和 keystore，避免签名文件、密码或别名混用。
- Android CI 拆分为独立的 PR、Debug 和 Release workflow；PR 不读取签名 Secret，Debug 和 Release 分别生成对应签名产物。
- 首页和用量页的 2×2 指标卡统一尺寸与内容对齐，较长辅助文字不再撑高单个卡片。
- 修复凭证额度响应的 Kotlin Serialization 反序列化调用，确保 Debug Kotlin 编译兼容当前依赖版本。

## English

This patch adds read-only credential quota and improves signing pipelines and metric-card layout.

- Operations now includes a credential-quota entry showing active Codex credentials, plans, and used, remaining, and reset information for 5-hour and weekly limits.
- Credential quota is queried securely through the Manager Server. OAuth tokens never enter the Android client, and quota responses are not persisted locally.
- Debug and Release now use separate GitHub Secrets and keystores, preventing signing files, passwords, or aliases from being mixed.
- Android CI is split into dedicated PR, Debug, and Release workflows. Pull requests do not read signing secrets, while Debug and Release produce their respective signed artifacts.
- The 2×2 metric cards on Overview and Usage now share consistent dimensions and content alignment, without long supporting text stretching individual cards.
- Fixed Kotlin Serialization deserialization for credential quota responses to compile with the current dependency version.
