# CPAMP Mobile 1.3.0

这一版本让凭证额度页可以直接在 Manager Server 上发起一次性巡检，并继续打磨更新详情、监控概览和卡片描边的视觉细节。

## 中文

### 🚀 服务端巡检

- 凭证额度页新增「运行巡检」，可请求 Manager Server 立即执行一次 CPAMP 巡检，无需前往网页端操作。
- 启动后提示稍后刷新以查看结果，并区分 Admin Key 无权限、旧版服务端不支持、网络错误、限流和服务端启动失败等状态。
- 手机端仍从不直接查询提供商接口，巡检执行与额度计算完全由服务端完成。

### 🎨 界面打磨

- 设置中的应用更新详情面板对齐更整齐。
- 请求监控的概览区域更紧凑，信息密度更合适。
- 登录、图表、监控、设置等页面的卡片描边更柔和，视觉更轻盈。

## English

This release lets the credential quota screen request a one-off server inspection and refines the update details sheet, monitoring overview, and card outlines.

### 🚀 Server inspections

- The credential quota screen now has a "Run inspection" action that asks the Manager Server to execute a CPAMP inspection immediately, without opening the web interface.
- After starting, the screen asks you to refresh when the inspection finishes, and distinguishes unauthorized, unsupported-server, network, rate-limit, and failure states.
- The phone still never queries provider APIs directly; inspections and quotas are computed entirely by the server.

### 🎨 Interface polish

- The update details sheet in Settings is aligned more consistently.
- The request monitoring overview is more compact with a better information density.
- Card outlines across login, charts, monitoring, and settings are softer and lighter.
