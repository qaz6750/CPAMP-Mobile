# CPAMP Mobile 1.3.9

这是一个针对 Accounts 单元测试的发布构建热修复版本。

## 中文

- 修正 Direct quota 请求失败场景的测试夹具，使其与生产路径携带的 `ProviderRequest` 失败原因保持一致。
- 保留服务器 inspection 返回的额度窗口，同时验证 Direct quota 刷新失败提示不会丢失。
- 修复 `AccountHealthMappingTest` 导致的 `testDebugUnitTest` 发布流水线失败。

## English

This is a release-build hotfix for the Accounts unit tests.

- Aligned the failed direct quota test fixture with the `ProviderRequest` failure produced by the application path.
- Preserved server inspection quota windows while verifying that direct quota refresh failure context remains available.
- Fixed the `testDebugUnitTest` release pipeline failure in `AccountHealthMappingTest`.
