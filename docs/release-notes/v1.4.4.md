# CPAMP Mobile 1.4.4

本版本修复概览、账号健康与账号详情的显示布局，统一提供商图标，并清理构建警告。

## 中文

### 📊 概览与账号

- 恢复概览与用量统计卡片的固定 2×2 网格，不再随屏幕宽度切换为单列或四列。
- 账号健康总览恢复为四项 2×2，新增总账号，并保留正常可用、额度风险与需要处理统计。
- 统一账号健康中的提供商图标样式，移除额外的方形底板。
- 移除账号健康页标题下方的 Management 辅助文案。
- 恢复账号详情本轮凭证用量为 2×2，预计周期成本在下方独立整行展示。
- 将“今日热门模型”改为更准确的“今日模型用量”，英文同步为 Model usage today。

### 🛠️ 构建与质量

- 页面标题组件支持省略副标题，修复账号页因移除副标题导致的编译错误。
- 清理多余安全调用、弃用图标引用与恒真条件等 Kotlin 编译警告。
- 迁移至 AGP 9 内置 Kotlin 与新 DSL，移除旧 DSL 开关与弃用的 kotlin-android 插件。

## English

This release fixes the dashboard, account health, and account detail layouts, unifies provider icons, and cleans up build warnings.

### 📊 Overview and accounts

- Restored a fixed two-column grid for overview and usage metric cards on all screen widths.
- Reworked the account health overview into a 2×2 grid with total accounts plus healthy, quota risk, and attention counts.
- Unified provider icon styling in account health by removing the extra square backdrop.
- Removed the Management subtitle from the account health page header.
- Restored the current-cycle usage section to a 2×2 layout with projected cost on its own row below.
- Renamed “Top models today” to the more accurate “Model usage today”.

### 🛠️ Build and quality

- Made page header subtitles optional, fixing the compilation error after removing the account page subtitle.
- Removed unnecessary safe calls, a deprecated icon reference, and an always-true condition.
- Migrated to AGP 9 built-in Kotlin and the new DSL, dropping the legacy DSL toggles and the deprecated kotlin-android plugin.
