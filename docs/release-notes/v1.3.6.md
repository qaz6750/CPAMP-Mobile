# CPAMP Mobile 1.3.6

这一版本重新聚焦只读管理与健康检查，简化顶层功能，并全面接轨 CPA-Manager-Plus 的视觉语言。

## 中文

### 👤 Accounts 健康中心

- 新增只读 Accounts 健康中心，集中展示账号状态、提供商、套餐和额度窗口。
- 支持按提供商筛选，并提供账号总数、健康、需关注、额度风险、已禁用和待检测概览。
- 账号详情展示数据来源、观测时间、剩余额度、重置时间和异常状态，不提供凭据写入操作。
- 对检查结果和本地缓存进行隐私保护，账号身份仅在当前会话内保留。
- 额度健康分级与 CPA-Manager-Plus 对齐，采用 `70%` 和 `30%` 阈值。

### 🧭 功能与导航精简

- 移除 Operations 模块及相关写操作入口，避免在移动端暴露高风险管理能力。
- 移除 Monitoring 请求事件列表与详情，仅保留适合移动端快速查看的聚合摘要。
- 将服务器新增、切换和管理统一迁入 Settings，减少重复入口。
- 调整顶层导航顺序，并用 Accounts 替代原有独立额度页面。

### 🎨 UI 与配色

- 对齐 CPA-Manager-Plus 的浅色与深色主题，包括页面渐变、表面、边框、文本和语义状态色。
- 恢复卡片、面板和底部导航的分层圆角，保持移动端清晰的视觉层级。
- Accounts 使用连体提供商筛选、独立数量标签、紧凑账号卡和分层额度卡片。
- 统一登录、设置、监控、分析和图表页面的表面与间距。

## English

This release refocuses the app on read-only administration and health inspection, simplifies its top-level features, and aligns the visual language with CPA-Manager-Plus.

### 👤 Accounts health center

- Added a read-only Accounts health center for account status, provider, plan, and quota windows.
- Added provider filtering and overview metrics for total, healthy, attention, quota risk, disabled, and pending accounts.
- Account details show the data source, observation time, remaining quota, reset time, and failure state without credential write operations.
- Inspection results and local cache data are privacy-safe, while account identity remains in memory for the current session only.
- Quota health levels now match CPA-Manager-Plus with `70%` and `30%` thresholds.

### 🧭 Simplified features and navigation

- Removed the Operations module and its write-action entry points to avoid exposing high-risk administration on mobile.
- Removed Monitoring request-event lists and details while retaining aggregate summaries for quick mobile review.
- Moved server creation, switching, and management into Settings to eliminate duplicate entry points.
- Reordered top-level navigation and replaced the standalone quota page with Accounts.

### 🎨 UI and colors

- Aligned light and dark themes with CPA-Manager-Plus, including page gradients, surfaces, borders, text, and semantic status colors.
- Restored layered corner radii across cards, panels, and bottom navigation for a clear mobile hierarchy.
- Accounts now uses connected provider filters, separate count pills, compact account cards, and layered quota cards.
- Unified surfaces and spacing across login, settings, monitoring, analytics, and chart screens.
