# CPAMP Mobile 1.3.3

这一版本修复实时凭证额度查询，并改进请求事件详情、耗时辨识和指定月份选择。

## 中文

### 📊 凭证额度

- 凭证额度页移除容易混淆的巡检操作，只保留 Manager Server 实时额度刷新。
- 修复额度代理请求的 `auth_index` 字段，使 Manager Server 能够正确定位凭证。
- 兼容数字或字符串形式的凭证索引，以及省略内部状态码的成功响应。
- 单个凭证暂时无法获取额度时使用更简洁的提示，不影响其他凭证结果。

### 🔎 请求事件

- 请求详情改为居中悬浮卡片，不再从屏幕底部弹出。
- 详情移除端点，新增服务来源和思考 Token。
- 首字耗时和总延迟根据快、中、慢分档显示绿色、橙色或红色。
- 调亮请求成功状态条，提升浅色与深色界面中的辨识度。

### 📅 指定月份

- 指定月份现在只显示最近 12 个月内实际存在请求或 Token 数据的月份。
- 没有可用月份时隐藏指定月份入口，避免进入空白报告。

## English

This release fixes live credential quota queries and improves request event details, duration visibility, and month selection.

### 📊 Credential quotas

- The credential quota screen now focuses on live Manager Server refreshes without the confusing inspection action.
- Fixed the `auth_index` field sent to the quota proxy so Manager Server can locate credentials correctly.
- Added compatibility for numeric or string credential indexes and successful responses without an embedded status code.
- A temporarily unavailable credential now shows a concise message without affecting other quota results.

### 🔎 Request events

- Request details now open in a centered floating card instead of sliding up from the bottom.
- Endpoint details were removed, while service source and reasoning tokens were added.
- Time to first token and total latency use green, amber, or red based on fast, moderate, and slow thresholds.
- The successful request accent was brightened for clearer visibility across themes.

### 📅 Selected months

- Month selection now lists only months from the last 12 months that contain request or token data.
- The selected-month entry is hidden when no eligible month is available, avoiding empty reports.
