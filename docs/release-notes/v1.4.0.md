# CPAMP Mobile 1.4.0

此版本重点改进启动加载、账号健康与额度周期用量，并更新 Android 构建工具链。

## 中文

### ⚡ 启动与加载

- 登录后立即预加载概览、账号健康和用量分析数据，减少首次进入页面时的等待与手动刷新。
- 账号清单直接从 Management 凭据数据加载，不再依赖服务器巡检，并改进账号与统计数据的匹配。

### 📊 账号与额度周期

- 账号详情按各自最近一次额度重置计算当前周期用量，不再固定统计自然月；相同周期合并请求并限制并发。
- 合并账号页面重复的错误、缓存和用量提示，同时升级缓存格式，避免短暂显示旧的月度统计。

### 🛠️ 构建与兼容性

- 升级至 AGP 9.3.1、Gradle 9.5.0、Kotlin 2.4.10、Lifecycle 2.11.0、Room 2.8.4、OkHttp 5.4.0 和 Hilt 2.60.1，并使用 API 37 编译。
- 修复 Compose 资源访问 lint 问题以及 Kotlin 2.4 元数据相关的 Hilt 构建兼容问题。

## English

This release improves startup loading, account health, quota-cycle usage, and the Android build toolchain.

### ⚡ Startup and loading

- Preloads overview, account health, and usage analytics data immediately after sign-in, reducing first-open waits and manual refreshes.
- Loads the account inventory directly from Management credentials instead of depending on server inspection, with improved account-to-statistics matching.

### 📊 Accounts and quota cycles

- Calculates each account's usage from its most recent quota reset instead of the calendar month, grouping equal ranges and limiting concurrent requests.
- Consolidates duplicate error, cache, and usage notices, and upgrades the cache format to prevent stale monthly statistics from appearing briefly.

### 🛠️ Build and compatibility

- Updates to AGP 9.3.1, Gradle 9.5.0, Kotlin 2.4.10, Lifecycle 2.11.0, Room 2.8.4, OkHttp 5.4.0, and Hilt 2.60.1, compiling against API 37.
- Fixes the Compose resource-access lint issue and Hilt build compatibility with Kotlin 2.4 metadata.
